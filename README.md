# 🕹️ 网页小游戏 (Mini Arcade)

纯前端网页小游戏合集 —— 无需安装、无需服务器,双击 `index.html` 即开即玩,支持键盘与触屏。

- ✅ 咬文嚼字 —— 原创机制：**一串没有标点的字，刀落在哪儿意思就是什么**。「下雨天留客天留人不留」，主人贴的是逐客令，客人念出来是赖着不走。每句藏着 2-3 种读法，**全部咬出来才算过**；试读一次吃一口口粮，读不通也吃，读完只告诉你「还差几刀 / 多切几刀 / 哪刀落错了地方」。语料 15 句 31 种读法，取自解缙春联、《邹忌》《狼》《口技》的**课文断句考点**（把「今齐地，方千里」读成「今齐，地方千里」正是要抓的误读）与教材歧义例句；读法只写标点版，断点由代码反推，测试逐条核对，写错一个标点就报错，绝不会做出死题。本意/别解/误读三档给分，别解比本意值钱，连击最高 ×2
- ✅ 一笔画 —— 原创机制：**点阵里藏着一幅画的所有线段**。关卡由「不重复边的随机游走」生成，那条游走本身就是解；每描一条线都用**欧拉通路定理**判一次（没描的线必须连成一片、奇数度的点恰好 0 个或 2 个且笔尖正站在其中之一上），于是**走出去才发现「怎么走都描不完」的那一笔会当场判死笔**，洗一笔费一滴墨，墨尽判负。棋盘从 3×3 升到 5×5，每关线数 = 4+关卡，`不许洗笔` 档只给 1 滴墨 1 次提示
- ✅ 分拣工厂 —— 传送带**不改路、只改方向**：9×6 车间每一格地板就是一个箭头，包裹顺着箭头一路走到底。你手里只有扳手，**转一格花一把**（隔一段时间补一把，转错一格全场当场改道）：🧊 冰鲜进冷藏柜、🏺 易碎进软垫架、💰 贵重进保险柜、📦 普通上普通货架，送错 / 掉出流水线 / 时限内没送完都扣信誉，大促档还塞加急件。找路用 **0-1 BFS（只把转弯算代价）**，所以提示给出的永远是「最少要拧几把」
- ✅ 绝对音感 —— 原创机制：三种听力轮次轮换：**辨音程 / 跟弹旋律 / 听和弦性质**（大小增减挂四与三个七和弦）。音高全部用 WebAudio 现场合成（MIDI → 440·2^((n-69)/12)），**耳力是唯一资源**：答错扣分但**退还一次回放**，耳力（答错就扣）与回放次数都是难度给的：热身房 8 耳力 5 次回放，琴房 4/3，**演奏厅档只给 1 耳 1 回放——一遍定生死**，而且演奏厅档一半的音程**倒着弹**（高→低），连方向都是考点
- ✅ 钓鱼佬 —— 两段式：**黑漂那一下拼反应，中鱼之后拼遛法**。按住收线张力就涨、线长就缩，松手张力回落、鱼往外切；鱼每猛窜一次自己掉一层劲，**它窜的时候硬拉必断线**，遛到没劲才起得了鱼。断线扣一副线，线尽或天光耗尽收竿；清晨/正午/夜钓三档，**夜钓真把大货率从 58.9% 抬到 69.3%**（青鱼王 14.6%→19.3%），打窝、换水层、鱼篓图鉴各算一笔账
- ✅ 多米诺 —— **自己一张一张摆骨牌**，按下第一张之后一切交给递推：每张牌倒下时顶端画出半径 = 牌高的圆弧，只有落在下一张牌内侧、**命中点够高**（擦着牌尖推不动）、**转角够顺**（太拧的弯传不过去）才算接上，一张牌能同时拍倒两张所以链会分叉。🪨 挡路、💧 水坑泡不得、⚡ 站上弹板这一拍能跨 1.35 倍、💎 顺路扫到有奖；9 关（直巷 / 绕桩 / 水坑 / 弹板 / 捡钻石 / 九曲 / 窄门 / 大戏台 / 自由场）×三档规格（牌高 50/40/32，越矮越难接也越值钱），**摆得疏省牌得高分，摆太疏就断链**
- ✅ 虫食算 —— 竖式让虫蛀掉几个数字，**只能按位往回推**：个位对不上就往十位借，进位借位一笔笔记在草稿带上。挖空之前先用穷举法验过「恰好一解」才敢出题；**填错一次，虫当场再吃掉一格你原本看得见的数**（咬完仍保证有解，只是信息少了），三档难度（入门只咬一次 / 贪婪咬两次 / 饕餮咬完还换题），连对有奖励、换题要扣钱
- ✅ 摸黑 —— **你走一步，守卫才走一步**的回合制潜行。守卫按固定的换岗路线与朝向巡逻，光锥（半角 45°）照到的格子站进去就报警；出题时用「不扔石子」的 BFS 现场证明这一关有解，那条解就是 par 步数，所以**背板就是实力**。🪨 石子能把守卫调开属于额外手段，因此「不用石子也有解」永远成立；8 张手工牢房 × 三档视野，被抓退回本关开头、警报耗尽才出局
- ✅ 移个车先 —— 6×6 停车场里的 Rush Hour：**每辆车只能沿车头那根轴滑，滑多远都算一次**，把红车开到 🚪 就出库。关卡是**在滑动图上从出口倒着推出来的**（先把红车停在出口，再立几辆竖车当门，横车一律不许进出口行），所以局局有解、绝无死局；招牌上的「最少挪几次」是现场 BFS 算出来的，提示也就永远是最优第一步。三档难度、十场越来越堵，地址栏写 `#seed=数字` 可与朋友比同一串停车场
- ✅ 面馆高峰期 —— 时间管理：**一份面要过三道手**（🔥 下锅 → 🥘 炒浇头 → 🛎️ 上桌），而店里只有一口锅一口炒锅。全场用一个整数「拍」（0.1 秒）当时钟，出单间隔、煮面、炒锅、耐心全部按拍计数，所以**任何时刻的局面都能逐步推算**；面熟了还赖在锅里 7 秒就坨，坨了只能倒掉重做，客人等超时拂袖而去，信誉扣光就关张。时段每 60 秒升一级：出单更快、耐心更短，攒够时段才加锅
- ✅ 鼓机十六步 —— 先当作曲家再当鼓手：**4 条声部 × 16 步**的网格上点出鼓点，机器替你循环播放；按 ▶ 演奏之后鼓声就归你了——节拍器只留四下 clicks，该敲的那一拍必须在毫秒级判定窗内按对道（PERFECT / GOOD / MISS），**漏掉那一拍只剩一声闷响**。音符越密风险倍率越高，每三段提速一档，段与段之间幽灵鼓手还会往你的拍子里塞花（⚡ 可以留着也可以删掉）
- ✅ 推箱子 —— 经典仓库解谜：**箱子只能推不能拉，也不能隔着箱子推**，走错一步就得整局倒退。关卡是**从「已经码好」的局面倒着拉乱**生成的（拉箱前先确认人绕得到箱子另一侧），所以局局有解；招牌上「最优 N 步」是现场 BFS（状态 = 仓管员位置 + 箱子集合）搜出来的**真最短**，走得越贴它倍率越高，用完「最优 + 富余」步数还没清库就扣一次加班额度。三档（小仓库 6×6 / 中班 7×7 / 爆仓 8×7）、十关、撤销随便按、提示直接告诉你「最优还剩几步」，`#seed=数字` 可与朋友比同一张仓库图
- ✅ 连连看 —— 眼力 + 手速：**两张同样的牌，通路只穿空位和外圈、拐弯不超过两次**就算连上，连线当场画给你看（判定和画线是同一套代码：按拐弯次数分层的射线 BFS）。牌阵比可视范围多一圈「外走廊」，贴边的牌永远绕得出去；全场用一个整数「拍」（0.1 秒）当时钟，倒计时、连击窗口、连线残留全按拍算，**任何时刻的局面都能逐步推算，不会有浮点漂移**。2.5 秒内接着消就叠连击，牌面一旦没得连先免费洗牌、洗牌次数用完当场散场。8 关（热身 → 收官）× 三档（眼疾 6×4 / 手快 8×5 / 老手 10×6）
- ✅ 打砖块 —— 街机拆墙：**球打在挡板的哪一段就往哪边飞**，边缘够斜、中间够直，弹道是自己调出来的；撞砖按「穿透最浅的那根轴」反弹，所以永远不会有磨地球。连锁只认「不挨挡板」，敲碎才加、回到板上就清零，越连越值钱；五种砖阵花样（横条 / 棋盘 / 金字塔 / 竖条 / 钻石），血厚的砖要挨好几下才碎；敲下来的水泡**必须用板子接住**才生效——⬌ 扩板、⚪ 分裂球（场上最多 4 颗）、🐌 放慢节奏。12 关封顶、三档（松一松 4 命 / 街机厅 3 命 / 硬核 2 命且板只剩 70px），`#seed=数字` 复现同一面墙和同一串掉落
- ✅ 接根水管 —— 原创机制：**水已经在流，你边漏边接**。管口是位掩码（上 1 右 2 下 4 左 8），点一下顺时针转 90°；水每过一拍往管口对得上的邻格灌一格，**灌出去的水不回退**，接口没对上就当场漏水，漏几处时间就按几倍掉。出题先生成一条**必定接通**的管路（随机 DFS 主路 + 一段回环岔路，三通四通就是这么来的），再撒几根假管子、钉上几个开局就对好的 🔒 固定接头，最后打乱旋转——因此**全部拧回正位必然零漏水**，出水口见水即过关，一滴不漏另发一笔干爽奖金
- ✅ 跳一跳 —— 按住蓄力、松手起跳：**蓄力时长决定水平距离**（`26 + 0.58t + 0.00012t²`，满力 1166px）和滞空时间，所以跳远绝不是按满就行；落在台面正中 ±11px 吃 PERFECT 并叠连击倍率，踩到边上只有 6 分底奖，一脚踏空连击清零；一跳跨过好几台按台数加分。想站桩等机会？**站着不动超过 8 秒（硬核档 4.6 秒）当场超时判负**，跳太高撞上台沿一样扑空。台面间距、宽度、高低差都保证「每一档 16ms 的蓄力都必须有落点」，20 级封顶，`#seed=数字` 比同一条台路
- ✅ 华容道 —— 二十格木匣里只剩两个空位：**木块只能整格横竖滑，不能旋转、不能抬手跨过、更不能叠**。招牌上的「最优 N 步」是现场 BFS（状态 = 占用图 + 曹操所在格，同类木块互换算同一局）算出来的**真最短**，走得越贴它分越高；八关里前七关是**自己出的题**（把出口钉死、从已解盘面按层铺开取最外层候选，再正向 BFS 精确验步，所以既不会出死局也不会出「滑两下就赢」的软题），收官是老祖宗的原题**横刀立马**（112 步）。撤销、按步计分、走满最优 + 富余就扣加班额度
- ✅ 24 点速算 —— 四张牌、三个运算符名额：**每次挑两张配一个 ＋－×÷，两张塌成一张**，合到剩最后一张正好等于目标才算过。中间值一律用分数精确存（3 3 8 8 只能靠 8÷(3−8÷3)），除零非法，减法除法看选牌先后。发题前用穷举求解器验「确实合得出来」，每合一步再验一次——一旦剩下这几张无论怎么合都到不了目标，当场判**算死了**，只能撤销或换题。三档：慢慢算（只发纯整数题）/ 标准局 / 抢答赛（目标轮换、非分数不可、还带连击窗口）
- ✅ 数圈 —— 每格数字说的是「**周围 8 格里有几格在圈上**」：点格子把它画进圈、或打个 ✕ 做记号，圈上的格必须连成**一条**闭合回路（每格恰好 2 个上下左右的圈邻居，不能断、不能分叉、也不能画成两坨），且每个数字都要对上。题目现造现验：先造一条结构上必定合法的环（矩形框的 L 边 + 楼梯边）翻几次角，再随机放数字、逐个试删，**每删一个都跑一遍带传播的回溯求解器确认只剩一个解**才发——所以提示揭示的格子永远不会与答案打架。八关从 4×4 画到 8×8，地址栏 `#seed=数字` 可与朋友比同一串盘

## 首页进度中心

首页会自动读取各游戏写在 `localStorage` 里的纪录,不需要任何后端:

- **统计条** —— 玩过 N/48、累计最高分、纪录条数;蜘蛛纸牌已扣除 500 起步分,只有真正超过起步分才计入
- **筛选** —— 全部 / 已玩 / 没玩过 + 标签(经典、益智、射击、纸牌、消除、休闲、音乐、塔防、文字、物理、解压、数字、记忆、构筑、图形、空间、对战、棋类、策略、反应、收集),带数量角标;筛选栏滚动时吸顶
- **多列卡片** —— 竖排紧凑卡片,桌面 4 列 / 平板 2-3 列 / 手机 2 列,48 个游戏十来屏看完
- **卡片纪录** —— 每张小卡片上直接显示最高分 / 最佳用时 / 已通关卡 / 最远轮次,对战游戏显示胜场与最长连胜,玩过的游戏打上 ✓ 标记
- **继续未完局** —— 数独 / 算独 / 数织 / 魔方 / 四款棋类留有未完局存档时,顶部出现一枚「继续未完局 · 已下 12 手 · 轮到白」之类的快捷入口(按注册表顺序取第一枚,数独优先)
- **清空纪录** —— 一键清掉本机所有纪录与设置(会二次确认),只删 `localStorage`,不动任何游戏文件

> 纪录跟着**来源**走:`file://` 本地打开与 GitHub Pages 域名是两个不同的 origin,数据互不相通;换浏览器、换设备或开无痕窗口同样看不到旧纪录。

## 新增一个游戏

1. 在项目根目录新建文件夹（如 `dino/`），放 `index.html` + `style.css` + `game.js`；
2. `index.html` 里先引 `../shared/base.css`，再引自己的 `style.css`（只写差异），音效用 `../shared/sfx.js`：
   ```html
   <link rel="stylesheet" href="../shared/base.css">
   <link rel="stylesheet" href="style.css">
   <script src="../shared/sfx.js"></script>
   <script src="game.js"></script>
   ```
   可用主题变量：`--accent` / `--accent-2`（渐变主色）、`--app-width`（正文宽度）、`--board-ratio`（画布宽高比）；
3. 在 `home.js` 的 `GAMES` 数组中登记一条（`id`/`emoji`/`name`/`desc`/`tags`/`href`），首页卡片即自动出现；
4. 补上 `prefix`（该游戏的 `localStorage` 键前缀）与 `records()`（卡片上展示的纪录），`totals()` 可选，否则首页统计与「已玩」识别会漏掉它；
5. 跑一遍 `node tools/selfcheck.js`（结构/键名/首页渲染）与 `node tools/smoketest.js`（能不能真跑起来），全绿再提交；
6. 想留住玩法细节，就在 `tools/tests/` 加一个 `<游戏目录>.test.js`：`require('../smoketest.js')` 拿到 `loadGame`，用桩模拟点格子/发射/落子，再用 `_assert.js` 的 `ok()` 断言，`report('名字')` 收尾 —— `run.js` 会自动发现它。

每个游戏完全自包含（不依赖外部库、不联网），保持“双击即玩”。`shared/` 只是仓库内的本地文件，同样零构建。

## 质量检查（全部零依赖、不需要浏览器）

```
node tools/tests/run.js --all   # 一次跑完下面三层
```

### 1. 静态自检 `node tools/selfcheck.js`

197 项检查，覆盖六类：JS 语法、游戏目录结构与离线可用、`GAMES` 注册表与 `localStorage` 键是否对得上（键名打错会直接报错）、首页在 DOM 桩里能否正常渲染（空纪录 / 静音 / 有纪录 / 存储被禁四种状态 + 筛选交互）、共享层可用性、以及仓库体积概览。纯静态分析 + `vm` 沙箱执行。

### 2. 冒烟测试 `node tools/smoketest.js`

自带 DOM / Canvas / WebAudio 桩，把每个游戏目录的 `game.js` 真的加载起来、启动主循环、模拟点击与按键，检查有没有运行期异常，并顺带打印每款的绘制与发声次数，用来确认「画面真的在动」。新增游戏只要走 `shared/` 通用结构，通常无需额外配置即可被覆盖到。也可以当库用：`const { loadGame } = require('./tools/smoketest.js')`。
